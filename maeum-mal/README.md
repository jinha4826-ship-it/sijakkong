# 마음말 💬

감정은 그대로, 말은 부드럽게 — 비폭력대화(NVC) 기반 **말 다듬기 웹앱**.
단일 `index.html` 파일로 동작하며, 설치 없이 브라우저에서 바로 열립니다.

- 라이브: <https://jinha4826-ship-it.github.io/sijakkong/maeum-mal/>
- iPhone은 Safari로 열고 **공유 → 홈 화면에 추가**를 누르면 앱처럼 전체 화면으로 실행됩니다.

## 세 가지 화면

### ✍️ 생각 정리
말로 꺼내기 전에 생각을 세 칸으로 나눠 적습니다.

1. 무슨 일이 있었나요? (사실만 1줄)
2. 내 안에서 걸리는 점은? (감정·이유) + 지금 감정 칩(선택)
3. 내가 진짜 원하는 건? (핵심 1가지)

정리하면 **사실 / 내 마음 / 원하는 것** 요약 카드와 "한 줄로 말하면"이 나옵니다.
- `기록에 저장` → 내 기록 탭
- `이 내용으로 말 만들기 →` → 말 다듬기 화면에 내용이 채워지고 3가지 톤 문장이 바로 생성

### 💬 말 다듬기
1. 상대(친구·연인·가족·직장·동료·지인) + 상황(거절·서운함·부탁·선 긋기·사과·화해) + 말투(존댓말/반말)
2. 지금 내 감정 6가지 중 하나
3. 속마음을 날것 그대로 적기 (예시 칩 4개)

결과는 **① 부드러운 전달 / ② 솔직·담백한 전달 / ③ 단호한 경계선** 세 가지.
카드마다 "왜 이렇게 바꿨는지" 한 줄, 복사 버튼, 저장 버튼이 있고,
아래 **NVC 포인트**(관찰·느낌·욕구·부탁)에서 문장의 뼈대를 확인할 수 있습니다.
결과 화면에서 상황 칩을 눌러 즉시 다시 만들 수도 있습니다.

### 🗂 내 기록
저장한 문장과 생각 정리를 모아 봅니다. 가장 많이 나온 상황·감정 통계, 개별 삭제, 전체 삭제.
**모든 기록은 기기(localStorage)에만 저장**되고 서버로 보내지 않습니다.

## 문장 엔진

외부 API나 키 없이 기기 안에서 100% 동작하는 한국어 규칙 기반 엔진입니다.

- 상대 5 × 상황 5 × 감정 6 × 말투 2 × 톤 3 = **900가지 조합**
- 입력한 속마음에서 소재(주말·약속·돈·일·연락·눈치·말투·사적인 부분 등)를 찾아 문장에 반영하고,
  가장 핵심 문장은 그대로 인용합니다.
- 감정마다 NVC 느낌/욕구를 연결하고(서운함→관심과 배려, 지침→쉬고 회복할 시간 등),
  존댓말·반말 어미를 끝까지 일관되게 유지합니다.
- 3,600개 문장 자동 검사(어미 혼용·빈 문장·템플릿 잔여물) 0건.

## 파일

- `index.html` — 앱 전체(스타일·엔진·화면 포함 단일 파일)
- `src/engine.js` — 문장 엔진
- `src/app.js` — 화면 로직
- `src/template.html` — 마크업/스타일 원본
- `build.py` — `src`를 `index.html`로 합치는 빌드 스크립트

```sh
python3 build.py
```
