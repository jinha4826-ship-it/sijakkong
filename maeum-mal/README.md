# 마음말 💬

내 언어로 마음을 꺼내는 연습 — 비폭력대화(NVC) 기반 **자기표현 앱**.
문장을 대신 써주는 앱이 아니라, 언젠가 앱 없이도 스스로 말할 수 있게 만드는 것이 목표입니다.
단일 `index.html` 파일로 동작하고, 설치 없이 브라우저에서 바로 열립니다.

- 라이브: <https://jinha4826-ship-it.github.io/sijakkong/maeum-mal/>
- iPhone은 Safari로 열고 **공유 → 홈 화면에 추가**를 누르면 앱처럼 전체 화면으로 실행됩니다.

## 두 가지 길

### 💬 지금 바로 말해야 해요 (10초 도움)
급할 때 쓰는 초안 경로입니다. 훈련을 강요하지 않아요.

1. 상대 · 상황 · 말투(관계별) · 지금 감정을 고르고, 속마음을 날것 그대로 적어요.
   대화 캡처를 붙여 브라우저 안(OCR)에서 글자만 읽어 채울 수도 있어요.
2. **부드럽게 / 솔직·담백하게 / 단호하게** 세 가지 초안이 나와요.
3. 복사해서 그대로 보내도 되고, 고쳐 써도 돼요. 저장은 직접 누를 때만.

### 🌱 내 마음을 연습하고 싶어요 (자기표현 훈련)
차분할 때 쓰는 훈련 경로입니다. 완성 문장을 먼저 주지 않아요.

1. **상황** — 누구에게, 어떤 일이 있었는지 적어요.
2. **사실 vs 해석** — 실제로 있었던 일(관찰)과 머릿속 해석·추측을 나눠요.
   단정하는 표현이 보이면 "한 번 확인해 볼까요?" 수준으로만 안내하고, 옮길지는 내가 정해요.
3. **감정과 욕구** — 지금 감정 하나, 그 아래 욕구(존중·이해·휴식·약속·경계·안정·인정·신뢰·자율·대화·공정함)를 골라요.
4. **내 문장** — [사실 → 감정 → 욕구 → 바라는 것] 뼈대 힌트만 보고 내 말로 한 문장을 써요.
   막힐 때만 **예시 힌트** 아코디언을 열 수 있고, 예시 문장에는 사실/감정/욕구/바라는 것이 색으로 표시돼요(학습용).
5. **스스로 점검** — 채점하지 않아요. 자기점검 질문 4개에 내 기준으로 답하고
   **"이 문장이 내 마음과 맞아요"**를 눌러야 저장돼요.
   예시를 열지 않고 끝까지 쓰면 **‘스스로 완성’**으로 기록돼요.

## 내 기록

- **자립도** — 훈련 중 예시 없이 완성한 비율
- **훈련 vs 바로 말하기 비율**, 자주 마주친 감정, 자주 필요했던 욕구
- **최근 연습 흐름** (스스로 완성은 초록 점)
- **대화 이후 회고** — 기록 카드에서 원할 때만 남겨요
  (전달했는지 / 대화 후 내 마음 / 다음엔 다르게 해보고 싶은 것)
- 기록에서 반복되는 감정·상황, 내가 직접 적은 패턴 메모, 관계·경로별 모아보기

**모든 기록과 회고는 기기(localStorage)에만 저장**되고 서버로 보내지 않아요.
이전 버전(v1.x)에서 저장한 기록도 그대로 읽어요.

### 백업과 복구 (v3)
- **내보내기** — `내 기록 → 백업과 복구`에서 기록·패턴 메모·피드백을 담은 JSON 파일(`maeummal-backup-YYYYMMDD-HHMM.json`)을 내려받아요. iPhone 홈 화면 앱에서는 공유 화면으로 넘겨 ‘파일에 저장’을 고를 수 있어요.
- **가져오기** — 같은 JSON 파일을 골라 **지금 기록과 합치기**(id·내용이 같은 기록은 건너뜀) 또는 **가져온 기록으로 바꾸기** 중에 선택해요.
- JSON이 아니거나 깨진 파일, 마음말 백업이 아닌 파일은 아무것도 바꾸지 않고 이유를 알려줘요.

### 작성 중 임시저장 (v3)
- 바로 말하기·연습에서 입력할 때마다 0.4초 뒤 기기에 임시저장하고, 앱을 닫거나 새로고침해도 이어서 써요(복원 시 ‘이어서 쓰고 있어요’ 안내 + ‘새로 쓰기’).
- 저장을 마치거나 처음부터 다시 시작하면 임시저장은 지워져요.

### 개인정보 안내
- `?` 안내 모달과 `내 기록` 탭에서 ① 저장하는 것 ② 저장 위치(기기 localStorage) ③ 외부 전송 없음(OCR도 기기 안) ④ 지우는 법을 안내해요.
- 전문: <https://jinha4826-ship-it.github.io/sijakkong/maeum-mal/privacy.html>

### 안드로이드·모바일 대응 (v3)
- `history.pushState`/`popstate` 기반 뒤로가기: 모달·초안 결과·탭에서 뒤로가기 버튼을 눌러도 앱이 바로 종료되지 않고 한 단계씩 되돌아가요.
- 320px~
 작은 화면 레이아웃, 입력창 포커스 시 키보드가 가리지 않도록 `visualViewport` 기반 하단 여백과 `scrollIntoView` 처리.
- `manifest.json` + 아이콘(192/512/maskable) + 서비스 워커(네트워크 우선, 오프라인 시 마지막 화면).

## 문장 엔진

외부 API나 키 없이 기기 안에서 100% 동작하는 한국어 규칙 기반 엔진입니다.
상대 5 × 상황 5 × 감정 6 × 말투 2 × 톤 3 조합으로 초안과 예시 힌트를 만듭니다.

## 파일

- `index.html` — 앱 전체(스타일·엔진·화면 포함 단일 파일)
- `src/engine.js` — 문장 엔진 (v1.x에서 이어받음, 그대로 사용)
- `src/app.js` — 두 경로 화면 로직·백업·임시저장·뒤로가기
- `src/template.html` — 마크업/스타일 원본
- `build.py` — `src`를 `index.html`로 합치는 빌드
- `privacy.html` — 개인정보처리방침 (Play Console 제출용)
- `manifest.json`, `sw.js`, `icons/` — PWA/안드로이드 패키징용
- `store/` — 스토어 스크린샷(1080×1920)·그래픽 이미지(1024×500)
- `android/` — 서명 키스토어·`.aab`/`.apk` (Play 업로드용, 저장소에는 올리지 않음)
- `play_store_prep.md` — 스토어 등록 문구·데이터 보안 체크리스트

```sh
python3 build.py
```
