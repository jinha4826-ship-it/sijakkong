# 마음말 💬

내 언어로 마음을 꺼내는 연습 — 비폭력대화(NVC) 기반 **자기표현 앱**.
문장을 대신 써주는 앱이 아니라, 언젠가 앱 없이도 스스로 말할 수 있게 만드는 것이 목표입니다.
단일 `index.html` 파일로 동작하고, 설치 없이 브라우저에서 바로 열립니다.

- 라이브: <https://jinha4826-ship-it.github.io/sijakkong/maeum-mal/>
- iPhone은 Safari로 열고 **공유 → 홈 화면에 추가**를 누르면 앱처럼 전체 화면으로 실행됩니다.

## 두 가지 길

### 💬 지금 바로 말해야 해요 (10초 도움)
급할 때 쓰는 초안 경로입니다. 훈련을 강요하지 않아요.

1. 상대 · 상황 · 말투(관계별) · 지금 감정을 고르고, 속마음을 날것 그대로 적어요.
   대화 캡처를 붙여 브라우저 안(OCR)에서 글자만 읽어 채울 수도 있어요.
2. **부드럽게 / 솔직·담백하게 / 단호하게** 세 가지 초안이 나와요.
3. 복사해서 그대로 보내도 되고, 고쳐 써도 돼요. 저장은 직접 누를 때만.
4. 더 내 상황에 맞는 문장이 필요하면 **[✨ AI 다듬기]**(v6) — 고른 관계·말투·감정과 적은 속마음을 바탕으로 실제 Gemini가 보낼 메시지를 다듬어 줘요. 앱 안에서 만든 세 초안은 그대로 남아 있어요.

### 🌱 내 마음을 연습하고 싶어요 (자기표현 훈련)
차분할 때 쓰는 훈련 경로입니다. 완성 문장을 먼저 주지 않아요.

1. **상황** — 누구에게, 어떤 일이 있었는지 적어요.
2. **사실 vs 해석** — 실제로 있었던 일(관찰)과 머릿속 해석·추측을 나눠요.
   단정하는 표현이 보이면 "한 번 확인해 볼까요?" 수준으로만 안내하고, 옮길지는 내가 정해요.
3. **감정과 욕구** — 지금 감정 하나, 그 아래 욕구(존중·이해·휴식·약속·경계·안정·인정·신뢰·자율·대화·공정함)를 골라요.
4. **내 문장** — [사실 → 감정 → 욕구 → 바라는 것] 뼈대 힌트만 보고 내 말로 한 문장을 써요.
   막힐 때만 **예시 힌트** 아코디언을 열 수 있고, 예시 문장에는 사실/감정/욕구/바라는 것이 색으로 표시돼요(학습용).
5. **스스로 점검** — 채점하지 않아요. 자기점검 질문 4개에 내 기준으로 답하고
   **"이 문장이 내 마음과 맞아요"**를 눌러야 저장돼요.
   예시를 열지 않고 끝까지 쓰면 **‘스스로 완성’**으로 기록돼요.
6. 완료 화면의 **[✨ AI 코치 한 줄 피드백]**(v6) — 잘 드러난 점을 짚어 주고, 더 자연스러운 대안 하나를 제안해요. 점수·등급은 매기지 않아요.

## 내 기록

- **자립도** — 훈련 중 예시 없이 완성한 비율
- **훈련 vs 바로 말하기 비율**, 자주 마주친 감정, 자주 필요했던 욕구
- **최근 연습 흐름** (스스로 완성은 초록 점)
- **대화 이후 회고** — 기록 카드에서 원할 때만 남겨요
  (전달했는지 / 대화 후 내 마음 / 다음엔 다르게 해보고 싶은 것)
- 기록에서 반복되는 감정·상황, 내가 직접 적은 패턴 메모, 관계·경로별 모아보기

**모든 기록과 회고는 기기(localStorage)에만 저장**되고 서버로 보내지 않아요.
이전 버전(v1.x)에서 저장한 기록도 그대로 읽어요.

### 백업과 복구 (v3)
- **내보내기** — `내 기록 → 백업과 복구`에서 기록·패턴 메모·피드백을 담은 JSON 파일(`maeummal-backup-YYYYMMDD-HHMM.json`)을 내려받아요. iPhone 홈 화면 앱에서는 공유 화면으로 넘겨 ‘파일에 저장’을 고를 수 있어요.
- **가져오기** — 같은 JSON 파일을 골라 **지금 기록과 합치기**(id·내용이 같은 기록은 건너뜀) 또는 **가져온 기록으로 바꾸기** 중에 선택해요.
- JSON이 아니거나 깨진 파일, 마음말 백업이 아닌 파일은 아무것도 바꾸지 않고 이유를 알려줘요.

### 작성 중 임시저장 (v3)
- 바로 말하기·연습에서 입력할 때마다 0.4초 뒤 기기에 임시저장하고, 앱을 닫거나 새로고침해도 이어서 써요(복원 시 ‘이어서 쓰고 있어요’ 안내 + ‘새로 쓰기’).
- 저장을 마치거나 처음부터 다시 시작하면 임시저장은 지워져요.

### ✨ AI 다듬기 · AI 코치 (v6, 2026-11-20)
- **경로**: 앱 → Cloudflare Worker(`https://maeum-bingsan-ai.cba4826.workers.dev`, `mode: "mm_draft" | "mm_coach"`) → Gemini `gemini-flash-lite-latest`.
- **언제 부르나**: 이용자가 버튼을 누를 때만. 앱이 스스로 호출하지 않아요.
- **서버 저장 없음**: Worker는 요청을 전달하고 응답만 돌려주며, 문장을 DB·로그에 남기지 않아요.
- **폴백**: 네트워크 오류 · 15초 타임아웃 · 모델 실패 · 기기당 하루 30회 한도에서 로컬 엔진 초안(또는 저장된 내 기록)으로 매끄럽게 돌아가고 짧게 안내해요.
- **프라이버시 문구**: `privacy.html` 4항과 앱 안내가 사실과 일치하도록 함께 고쳤어요 — 암호화(HTTPS) 전송, 서버 DB 미저장, Gemini 무료 등급이라 보낸 내용이 Google 서비스 개선에 쓰일 수 있다는 점(이름·연락처 등 개인정보 입력 자제 안내)까지 명시.

### 개인정보 안내
- `?` 안내 모달과 `내 기록` 탭에서 ① 저장하는 것 ② 저장 위치(기기 localStorage) ③ 외부 전송(AI 버튼을 누를 때만 암호화 전송, OCR은 기기 안) ④ 지우는 법을 안내해요.

### 네이티브 앱 셸 (v5)
- `html, body`는 고정하고 `.app`을 `100dvh`로 두었어요. 상단 앱바(제목 · 위기 안전 안내 · 사용법)와 하단 4탭(홈 / 즉시 도움 / 표현 훈련 / 기록·백업)은 고정이고, 본문 뷰만 안에서 부드럽게 스크롤돼요(스크롤바 숨김, `overscroll-behavior: contain`).
- 확인·안내는 모두 **드래그로 닫는 바텀시트**로 통일했어요(기록 삭제 확인 · 대화 이후 · JSON 가져오기 · 위기 안전 안내 · 사용법). 짧은 알림은 토스트로 떠요.
- Safe Area(`env(safe-area-inset-top/bottom)`)를 반영하고, 버튼·칩·탭·카드에 눌림 피드백(`:active` scale), `user-select: none`(입력창은 제외), `touch-action: manipulation`을 적용했어요.
- 입력창은 16px로 두어 iOS가 포커스 때 화면을 확대하지 않아요. 키보드가 올라오면 `visualViewport` 높이만큼 셸을 줄이고 탭바를 숨겨 입력창을 가리지 않아요.
- `history.pushState`/`popstate` 기반 뒤로가기: 시트·초안 결과·탭에서 뒤로가기를 눌러도 앱이 바로 종료되지 않고 한 단계씩 되돌아가요(`window.MMApp.handleBack()`은 안드로이드 WebView 래퍼용).
- 320px~ 작은 화면 레이아웃, `manifest.json` + 아이콘(192/512/maskable) + 서비스 워커(네트워크 우선, 오프라인 시 마지막 화면).
- **태블릿·가로모드(≥768px)** 에서는 앱 폭이 최대 `900px`(`min(94vw,900px)`)로 넓어지고, 홈의 두 길은 2열, 초안 3개는 3열, 내 기록은 2열로 보여요. 모바일(≤430px) 레이아웃은 그대로예요.

## 문장 엔진

기본 초안은 외부 API나 키 없이 기기 안에서 100% 동작하는 한국어 규칙 기반 엔진이 만들어요(✨ AI는 이용자가 버튼을 누를 때만 덧붙는 선택 기능).
상대 5 × 상황 5 × 감정 6 × 말투 2 × 톤 3 조합으로 초안과 예시 힌트를 만듭니다.

## 파일

- `index.html` — 앱 전체(스타일·엔진·화면 포함 단일 파일)
- `src/engine.js` — 문장 엔진 (v1.x에서 이어받음, 그대로 사용)
- `src/app.js` — 두 경로 화면 로직·백업·임시저장·뒤로가기
- `src/template.html` — 마크업/스타일 원본
- `build.py` — `src`를 `index.html`로 합치는 빌드
- `privacy.html` — 개인정보처리방침 (Play Console 제출용)
- `manifest.json`, `sw.js`, `icons/` — PWA/안드로이드 패키징용
- `store/` — 스토어 스크린샷(1080×1920)·그래픽 이미지(1024×500)
- `android-app/` — Android WebView 래퍼 프로젝트(Gradle) · `keystore/maeummal-release.jks` 서명 키
- `build.py`로 만든 `index.html`·`privacy.html`을 `android-app/app/src/main/assets/`에 넣고 `gradle bundleRelease`로 `.aab` 생성
- `play_store_prep.md` — 스토어 등록 문구·데이터 보안 체크리스트

```sh
python3 build.py
```
